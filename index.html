Real hardware data

One interface, every supported Windows generation

The universal release reads the Apple SMC directly. It never invents RPM values, limits, fan counts, or temperatures when hardware access is unavailable.

RPM

Dynamic fan detection

Enumerates the fans exposed by the SMC instead of assuming a fixed count. Each fan keeps its own reported minimum and maximum RPM.

°C

Real temperature sensors

Shows only sensors that are actually exposed and successfully read, including CPU, GPU, storage, and system categories.

SMC

Four control modes

Automatic, constant RPM, sensor-based control, and per-fan maximum speed—with live hardware-range validation.

42

Complete localization

Forty-two selectable interface and installer languages, including right-to-left support for Arabic, Hebrew, and Persian.

↻

Automatic restoration

Fans changed during the session are returned to Apple automatic control during a normal application exit.

PC

Native operating-system UI

XP uses XP visual styles, Vista and 7 use native Aero, and Windows 10 and 11 use their native controls and Shell-provided icons.

Read before installing

Low-level fan control carries real risk

!

Incorrect fan settings can cause overheating, crashes, accelerated component wear, data loss, or permanent hardware damage. This software is provided without warranty. You are responsible for deciding whether it is appropriate for your computer.

  • Keep the computer attended while testing a manual or sensor-based profile.
  • Never run two SMC or fan-control utilities at the same time.
  • Do not disable RPM safeguards or use unknown SMC keys.
  • A forced shutdown, crash, or power loss can bypass user-mode restoration.
  • The installer uses a privileged direct-I/O helper and requires Administrator access.
  • Windows XP, Vista, and 7 are out of Microsoft support; use them offline or in a controlled test environment.
